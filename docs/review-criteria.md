# 欠点指摘の基準

- **用途**：コードの欠点指摘で、Claude Code が走査に使う基準。欠点が見つかるたびに、同じ形の欠点を見つける基準として1行足すかを、人と対話AI で決める
- **書かないもの**：アカウントや鍵の守り方、サーバーの IP アドレスやアカウントの ID などの伏せる値、個人の名前、前のアプリの弱点（今も公開しているため）。このファイルは公開される
- 使い方は `docs/roadmap.md` の「各カードの進め方」にある

| 基準 | なぜ（出どころの方針） | 足した日 |
| --- | --- | --- |
| 画面と外の AI の窓口からの要求は、どれもサーバーが権限の判定を通しているか（認可の型に従っているか） | `docs/concept.md` の「状態の方針（1-2）」 | 2026-11-20 |
| ほかの人が書いた文字を表示する場所で、危ない部分を取り除いているか | `docs/ledger.md` の「ほかの人が書いた文字の表示」 | 2026-11-20 |
| 秘密の値（鍵・パスワード・トークン）を、コードや公開の文書に書いていないか | 導入の決まり（公開のリポジトリ） | 2026-11-20 |
| 画面全体の決まりに従っているか（日本語の変換を確定する Enter で、登録や送信をしない） | `docs/concept.md` の「画面全体の決まり」 | 2026-11-20 |
| 保存に失敗したとき、画面を最後にサーバーが認めた状態に戻し、エラーを見せているか | `docs/concept.md` の「状態の方針（1-2）」 | 2026-11-20 |
